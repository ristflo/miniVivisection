miniVivisection
Rhino 8 · Script Editor · Grasshopper

See inside your running scripts.

miniVivisection extends the debugger of Rhino 8's Script Editor. When a script stops, the geometry in its variables appears in Rhino's viewports; you can edit it with Rhino's own tools and send it back into the running script. Values show up right in the code, breakpoints get conditions, and Rhino stays usable the whole time.
